# 旋转木马部件说明文档

本文档整理演示项目中全部构件的结构作用与功能介绍，与程序内点击讲解面板（`js/config.js` 的 `PART_INFO`）内容一致。

## 模型层级总览

```
CarouselRoot（整机根，导出 GLB 的根节点）
├── BaseGroup            传动底座（静止）
│   ├── Base_Drum / Base_RingTop / Base_RingBottom
│   ├── Base_Platform    乘骑平台
│   └── Base_RingGear    内齿圈（透视模式可见）
├── ColumnsGroup         支撑立柱 ×8（静止）
├── CanopyGroup          顶棚（静止）
├── LightBeltGroup       装饰灯带（伞沿 + 平台两圈灯泡、4 盏点光源）
└── RotatingGroup        旋转组（随中心主轴公转）
    ├── CentralShaft     中心主轴（含顶部轴承、中部轮毂）
    ├── CentralShaft_DrivePinion  驱动小齿轮
    └── HorsePivot ×8    每个角度节点下含：
        ├── Arm          悬臂（钢梁 + 木马立杆）
        └── HorseBob → Horse  木马座椅（13 个独立小 Mesh）
```

---

## 1. 中心主轴（centralShaft）

- **结构作用**：旋转木马的核心承力与传动构件，竖直贯穿设备中心，上端连接顶棚轴承、下端连接传动底座内的驱动齿轮。
- **功能介绍**：运转时由底座电机经减速齿轮驱动，绕自身轴线匀速旋转。主轴通过中部旋转轮毂带动全部悬臂与木马座椅做水平公转，是整机旋转运动的动力来源与定位基准。
- **组成 Mesh**：主轴圆柱（`CentralShaft_Cylinder`）、顶部轴承座（`CentralShaft_TopBearing`）、旋转轮毂（`CentralShaft_Hub`）、驱动小齿轮（`CentralShaft_DrivePinion`）。

## 2. 顶棚（canopy）

- **结构作用**：固定在支撑立柱顶端的伞形顶盖，为乘骑区遮蔽日晒雨淋，同时是装饰灯带的主要安装载体。
- **功能介绍**：采用 `LatheGeometry` 旋转剖面生成的伞盖曲面，属于静止部件，不随主轴旋转。顶棚外缘与顶饰上布置装饰灯带，夜晚灯带开启后成为场景主光源，烘托游乐场氛围。
- **组成 Mesh**：伞盖曲面（`Canopy_Roof`）、伞沿金色压边（`Canopy_Eave`）、顶饰宝珠与尖杆。

## 3. 支撑立柱（column）

- **结构作用**：沿圆周均匀分布的 8 根承重立柱，下端固定于传动底座、上端承托顶棚，构成整机的固定框架。
- **功能介绍**：立柱保持静止，与旋转部件互不干涉，同时为顶棚载荷和灯带线缆提供传递路径。线框模式下可清楚看到立柱与旋转主轴、悬臂之间的空间关系。
- **组成 Mesh**：每根立柱含柱身圆柱、柱头与柱脚装饰球，共 8 组 24 个 Mesh。

## 4. 悬臂（arm）

- **结构作用**：从旋转轮毂水平伸出的放射状承重杆，内端固定在中心主轴的轮毂上，外端连接木马立杆。
- **功能介绍**：悬臂随主轴一起公转，将扭矩与向心力传递给每一个木马座椅，保证所有座椅在同一圆周上同步转动、彼此间距恒定，是“主轴带动木马公转”的直接传力部件。
- **组成 Mesh**：水平钢梁（`Arm_*_Beam`）+ 木马立杆（`Arm_*_Pole`），共 8 组。

## 5. 木马座椅（horse）

- **结构作用**：供游客乘骑的座椅单元，通过立杆悬挂在悬臂外端，沿圆周均匀布置共 8 匹。
- **功能介绍**：木马随悬臂做水平公转的同时，由立杆导向沿竖直方向做小幅上下起伏弹跳（幅度 ±0.18 单位，相邻马匹相位错开 180°），模拟马匹奔腾姿态。弹跳高度与频率随动画速度联动，形成经典的旋转木马节奏。
- **组成 Mesh**：每匹马由躯干、脖颈、头部、双耳、马鬃、马鞍、四条腿与蹄、尾巴共 **13 个独立 Mesh** 拼合，8 匹马使用独立材质实例并轮换 8 种马身配色。

## 6. 传动底座（base）

- **结构作用**：整机的地基与动力舱，内部容纳电机、减速齿轮组，外部承托平台、立柱与中心主轴。
- **功能介绍**：底座内部的大齿圈（28 齿）与小齿轮（14 齿）构成减速传动机构：电机带动小齿轮，小齿轮驱动与主轴相连的大齿圈，输出大扭矩低转速。切换到线框透视模式可直接观察齿轮啮合与内部结构。
- **组成 Mesh**：底筒壳体、上下金色箍边、木质乘骑平台、内齿圈。

## 7. 装饰灯带（lightBelt）

- **结构作用**：沿顶棚伞沿和底座平台外缘环形布置的装饰照明带，由灯串与灯泡组成。
- **功能介绍**：白天仅作装饰（弱自发光）；进入夜晚模式后灯泡自发光强度提升并自动点亮 4 盏配套点光源，成为场景主要照明，且带正弦呼吸闪烁；雨雾天气中光晕会被 `FogExp2` 雾气柔化，配合湿润地面形成夜间游乐场氛围。
- **组成 Mesh**：上下两圈各 24 个灯泡（共 48 个 Mesh）+ 4 盏 `PointLight`。

## 附：部件标识与 GLB 导出约定

- 每个部件根 Group 的 `userData.partId` 取值：`centralShaft / canopy / column / arm / horse / base / lightBelt`；
- 射线拾取时沿命中 Mesh 的父级链向上查找该标识，再从本文件对应的文案表读取讲解内容；
- 执行页面「导出 GLB」时，标识随 `userData` 一起写入 glTF 的 extras（r160 GLTFExporter 的 `serializeUserData` 行为，已核对源码），Mesh 名称（英文）完整保留，文件可在 Blender 等软件中按名核对上述结构；再次通过「导入 GLB」加载该文件时，GLTFLoader 会把 extras 还原回 `userData`，部件标识仍然保留。
