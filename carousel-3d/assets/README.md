# assets 资源目录

本目录用于放置静态资源（贴图、字体、音频、外部模型等）。

当前演示项目的旋转木马模型**全部由 `js/CarouselBuilder.js` 程序化生成**（Three.js 基础几何体 + PBR 材质），不依赖任何外部贴图或模型文件，因此该目录默认为空，仅保留说明文件。

如需扩展：

- 贴图文件（`.jpg/.png/.hdr`）可放入本目录并在代码中通过 `./assets/xxx.jpg` 相对路径引用；
- 外部模型可放入本目录，用 `GLTFLoader.load('./assets/xxx.glb')` 加载；
- 也可以直接使用页面顶部的「导入 GLB」按钮在运行时载入模型，无需改动代码。
